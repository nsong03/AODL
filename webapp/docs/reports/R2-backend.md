- §5.2 response: `"cuts": {…, "i_y": [...ny], …}`, `"gauss_peak": <float>, "exact_peak": <float>`;
  prose: `i_y` = XY column nearest the brightest spot's `x` over `xy.y_um`; all cuts closed-form
  (Eq. S11), SI power per m²; `gauss_peak = Σ 2·power/(π·wx·wy)` over spots within `w0` of the
  brightest; `exact_peak = max XY = xy.image.peak`; ratio ≈ 1 (≤ 2 % static at 3τ); dark frame →
  `gauss_peak = 0`; with a fixed/explicit plane the Gaussian value stays in-focus, so the ratio
  also measures defocus.
